夜班只有三只  ·  Windows x64 离线版

将整个 ZIP 解压到本机目录，再双击 Play.cmd。初次打开要等几秒钟创建存档。
引擎、Java 与 PostgreSQL 随包提供。通常无需管理员权限。退出游戏窗口后，
启动器会关闭本次使用的本地服务。请让它自行退出以保存通关记录。

在名册第一次按「开始」会先看到四页图解。左图标出了玩家、窗台、拉杆与南门。
点「明白了，开始试工」才发出第一单。标题页、名册和班内都能重看「玩法说明」。
在班内阅读会暂停游戏，点「返回本班」就从刚才的位置继续。
字幕默认开启。屏幕上会显示说话者、台词和有意义的声响。可用「字幕」按钮切换。

第一夜，地板上的小黄龙就是你。把鼠标移到正中 2 号窗的伙伴身上，
点一下左键送汽水。等交班票更新，再投下一瓶，三瓶都送这扇窗。
送完用 WASD 或方向键走到地板最下方正中央的门，靠近就能打卡。

第二夜起要辨认真伙伴。例如交班票写上单「← 左」，就在奶龙右边的
地板点一下右键弹瓶盖。看两扇窗，朝右伸手的伙伴才收这瓶，左键投给它。
上单向右就反过来试。后续出现护栏时，可瞄准侧墙反弹一次。

地板左下、右下的把手是备用泄压杆。投给冒牌货或压力耗尽时，
走到亮起的那根旁边会自动拉下，然后跑到下方正中央的南门逃生。

第三、四夜要留意釉面发亮的地砖和取货台。第五夜试着连续朝两侧弹盖。
第六夜开始会离开柜台，走进黑白木刻般的检修间观察录像；第七夜要录下
自己的动作，借回放开闸。第八夜先认住奶蛙的窗。它睡着时躲开红手印，
亮杆出现就靠近并按住左键稳机；铃响后走到窗前，右键试探、左键送瓶。
连续守过三轮就能推开最后的门。

正常启动使用本机 18737（游戏）与 55438（数据库）端口，地址仅绑定
127.0.0.1。存档与诊断日志在 %LOCALAPPDATA%\OnlyThreeOnShift。
如果这两个端口已被其他程序占用，可在解压目录打开 PowerShell，运行
.\Play.cmd -HttpPort 18739 -DatabasePort 55440

开发者可以运行 .\Play.cmd -QuickCheck，在独立的 verification 存档中自动
完成第一夜的三单和打卡。再运行一次可核对上次解锁记录。更完整的八关
输入回归可运行 .\Play.cmd -SmokeTest。请依次运行，以便本机端口复用。

引擎、数据库与 Java 的许可说明位于 app\licenses 与 app\java\legal。
