夜班只有三只 · 回收线 4.0  ·  Windows x64 离线版

将整个 ZIP 解压到本机目录，再双击 Play.cmd。初次打开要等几秒钟创建存档。
引擎、Java 与 PostgreSQL 随包提供。通常无需管理员权限。退出游戏窗口后，
启动器会关闭本次使用的本地服务。请让它自行退出以保存通关记录。

回收线怎么操作

第一次从名册开始夜班会先打开玩法说明。确认开工后输送带才会转。
标题、名册、班内都可以重看规则。班内打开手册会暂停现场。
字幕默认开启，环境动静和人物说话都会显示。

用 WASD 或方向键走位，鼠标瞄准。先沿输送带找出瓶颈将经过的白圈，
把小黄龙走到圈旁边。瓶颈进入圈时按下左键，接住后继续按着。
你可以带瓶走位，瞄到收货窗的缝隙再松开左键。每次接瓶都要重新按下。

第一夜练习接送。最后一瓶会意外弹回，横移到新的接瓶圈，再接住送出。
漏接时先看下层回收带，沿它的方向赶往下一个落点。完成工单后跟着出口提示下班。

右键会向准星弹瓶盖。真伙伴可以拦住盖子，假手会让它穿过去。
盖子可以敲管吸引柜下的东西，也能打中道岔拨片。留意脚下的回收带、
管口钢钉和瓶里的脚步。放出诱饵后，马上挪到回收带侧面。

第六夜看三段录像，先走几步、停一下，再比较谁慢了两秒。
第七夜录下踩板动作。站满两秒显示「可封存」，再点左键。
经过隔柱时分清「你」和「录像」，顺着箭头避开压辊。朝道岔弹盖开货槽，
把瓶送过闸。签收后走到门前白线，按住 D 或右方向键，等录像抬闸就能穿过去。
第八夜有三轮守窗。记住奶蛙的位置，一边跟着它换窗，一边守住中央机器。
后两轮压好第一根稳机杆，环内回收带就会启动。第二轮用右键弹盖拨岔。
第三轮把带声的瓶送上回收带，引开假窗，再赶到白圈接回它。
在倒计时内完成回收任务，逾时从当前这一轮开始。醒铃响后到奶蛙的
窗前，右键试探，确认回应再送瓶。

正常启动使用本机 18737（游戏）与 55438（数据库）端口，地址仅绑定
127.0.0.1。存档与诊断日志在 %LOCALAPPDATA%\OnlyThreeOnShift。
如果这两个端口已被其他程序占用，可在解压目录打开 PowerShell，运行
.\Play.cmd -HttpPort 18739 -DatabasePort 55440

开发者可以运行 .\Play.cmd -QuickCheck，在独立的 verification 存档中自动
走完第一夜的接瓶、松手送货和末单回接。再运行一次可核对上次解锁记录。更完整的八关
输入回归可运行 .\Play.cmd -SmokeTest。请依次运行，以便本机端口复用。

引擎、数据库与 Java 的许可说明位于 app\licenses 与 app\java\legal。
