# 夜班只有三只 · 回收线

八夜动作恐怖改版的设计稿。当前实机操作和每夜过关条件见[玩家手册](night-design.md)。

汽水厂只有三名员工。交班铃一响，输送带却会送来第四只空瓶。它装的是你刚才在车间里弄出来的声音。柜台下有东西听见了，正沿着管道寻找声音的主人。

## 玩家的两只手

左手移动，右手同时管两件事。你用瓶盖安排怪物下一秒看向哪里，用汽水瓶决定自己下一秒必须站在哪里。

| 操作 | 手感与后果 |
|---|---|
| WASD 走位 | 可边跑边瞄准。地板上的黄铜轨道标出瓶子经过的线路。站在轨道旁伸手才能接到它。胶垫能吃掉脚步声，铁板会把脚步传进管道。 |
| 右键弹盖 | 瓶盖朝准星实际飞出，可借一面带白边的铁板反弹。敲左侧管口，它就会转头朝左听；打进道岔的小拨片，还能改变下一只瓶的路线。每趟带三枚，补给架设在工位边。乱弹一地会把注意力引回自己脚边。 |
| 左键接、松手送 | 空手迎向来瓶，在瓶颈经过手边的白圈时按下左键。接住后继续按住，可以带瓶移动、转身瞄准，松开就朝准星送出。接瓶要求一次新的按下。接住的瞬间有清脆的「咔」、短暂停顿和瓶颈白边。 |
| 让瓶子替你出声 | 瓶内只保存最近三声脚步、管响或收货铃，保留间隔。瓶底三道刻痕亮出对应图案。放进空闲回收带，瓶子沿途逐声播放。拿这瓶调走怪物，稍后就得赶去接回自己的货。 |

柜下那只对单声会**转头**，对连续的脚步会**追过去**。每次转向前，最近管口先鼓包，随后钢钉沿着它走的方向逐颗弹起。玩家可以从墙上的动静确认诱敌有没有成功。诱饵从身边滚过，也能把它带到自己身边。

真实伙伴可以伸手拦住瓶盖。第四只隔着玻璃照样能做出漂亮的接盖动作，盖子却会从手掌里飞过去。这条差别从第二夜起一直有效。对熟练玩家，认窗、拨道岔、引开柜下的东西可以用同一枚精确反弹的盖子完成。

## 第四夜，回收线交叉口的一趟货

两条带在房间中央交叉。左边是慢带，右边是通往收货窗的快带。玩家看得见来瓶、道岔和收货窗；柜台下面只露出一排正在起伏的钢钉。

| 时刻 | 玩家眼前的事与手上的动作 |
|---|---|
| 0.0–1.3 秒 | 待送的汽水瓶沿慢带向左下滚。你斜向左下去截它，同时把鼠标瞄到右墙白边，弹一枚反弹盖。盖子敲响远端铁管，钉子开始向右跳。 |
| 1.3–2.4 秒 | 在左下交叉口踩住自己的接瓶位置，瓶颈经过白圈时按下左键。抓住以后手指保持按住，立即折向中央。身后那段胶垫被一排牙掀了起来。 |
| 2.4–4.0 秒 | 你可以边跑边瞄准，趁收货窗的窄缝经过准星直接松手。也可以提前把瓶送上内侧短带，腾出手再弹一盖拨道岔，多争一次接瓶机会。短带上的瓶会播出你刚才的脚步。 |
| 4.0–6.5 秒 | 走短带时，你得切过交叉口，躲掉循声伸出的手，转身接回改道的瓶。真伙伴的手压住了窗沿，窗缝逐渐合拢。瞄入缝内、松手，然后马上离开钢钉开始抬起的铁板。 |
| 签收后 | 铃响，伙伴低头。刚才那段脚步还在窗后走。近处的玻璃从里面猛地鼓出一张脸，你在后退时仍然能看见地面。下一趟来瓶前给短暂喘息。 |

短线奖励提前认窗、提前瞄准的玩家。走回收带能争取时间，也会多一次交叉走位和一次接瓶。漏接时，瓶子先落到下层回收带，熟练玩家可以抢救一次；碎了才从这趟货的入口重新开始。

## 八夜如何升级

| 夜班 | 这一夜要求的操作 | 玩家带去下一夜的发现 |
|---|---|---|
| 一 · 多了一只空瓶 | 暖灯下接一瓶、送一瓶。最后一趟瓶子意外弹回，要横移到第二个落点再接一次。首单落空会缓慢回流。 | 你走过铁板再踏上胶垫，脚步消失。下班后，第四只瓶子从空回收带里滚出来，瓶内是你刚才真实走过的节奏。 |
| 二 · 它也会伸手 | 一边横移接瓶，一边把盖擦过窗口。认出真正拦住盖子的伙伴，在会移动的收货槽前松手。 | 假手比真手伸得还殷勤。盖子穿过它后，离玩家最近的玻璃才响起牙齿磕碰声。 |
| 三 · 地板在听 | 带瓶穿过交错裂砖。先踩响铁板再撤步，等柜下的手扑空，从它刚离开的格子斜切出去，松手送瓶。弹远盖能改走另一条路。 | 手会追你的声音。它第一次扑空时，你能看见它掌心沾着第一夜回收瓶的标签。 |
| 四 · 交叉回收线 | 完成上面的交叉回收线。走位和准星常要朝相反方向，先选择路线，再连续接、拨、投、避。 | 怪物也会跟着瓶内的假脚步移动。你可以带着它走，也可能把它送到自己要去的接瓶点。 |
| 五 · 别接第四瓶 | 两只瓶子错峰入场。空瓶装着你的脚步，另一只是待送的货。你只有一双手，要在交汇前把其中一只拨去侧带，同时试出真窗。 | 留着空瓶就有移动诱饵，先把它放走则能腾出一条接货线。伪窗会随着铃声张嘴，必须在它冲出来前选定落脚点。 |
| 六 · 有人提前下班 | 三台监视器分别播放现场、延迟和旧录像。先做一个短促的折返确认延迟，再用带声的瓶引开管里的东西，抢在检修门合上前接回它。 | 旧录像重播你第一夜实际走过的路。在你离开之后，画面里那只还在往前走。没有旧记录的工牌使用标有「岗位示范」的路线。 |
| 七 · 替身压线 | 自己录一段踩板动作，把开闸时刻留给回放里的分身。压辊启动后，边绕柱边弹盖打开末端接货槽，把瓶送过闸，再跟着冲过去。 | 保留「你」「录像」和门前白线。闸落在背后的那一刻，替你扶门的分身朝玻璃张嘴。第一次真正贴到眼前的是一直在帮你的那只。 |
| 八 · 别叫醒奶蛙 | 三轮守夜。第一轮跟住换位窗。第二轮要同时稳机和改一次回收带。第三轮用带着自己脚步的瓶引开一面假窗，认住转到身侧的奶蛙，回身接瓶，趁它醒来送进去。 | 四面血口在最后一次正确签收后同时扑出。玻璃裂开时，前三夜那串脚步终于从玩家身后追到了脚边。 |

## 精度、节奏与重试

以下是首轮原型的**起测值**。按 480 × 288 的逻辑画布、20 Hz 服务端时钟计时。准星、瓶颈白圈、窗缝均由同一份实际轨迹绘制。

| 难度 | 接瓶时机 | 接瓶中心容差 | 一段连续操作 |
|---|---|---|---|
| 第一、二夜 | 9–11 tick，约 0.45–0.55 秒 | 14 逻辑像素 | 每段 2–3 秒，先学接放，再加入横移与弹盖 |
| 第三至五夜 | 6–8 tick，约 0.30–0.40 秒 | 10–12 逻辑像素 | 每段 5–7 秒，两次换向，一至两次接投，加一次独立瞄准的弹盖 |
| 第六至八夜 | 5–6 tick，约 0.25–0.30 秒 | 8–10 逻辑像素 | 高潮 6–9 秒，连续完成截瓶、横移、反弹、转身送瓶和撤离。高潮过后留出几秒听厂房 |

- 每次需要急转的来瓶提前至少 0.8 秒露出轨迹。高难度来自同时处理方向、时机和去向。强制扑脸落在最后一个关键输入之后，持续动作中出现的脸从侧面压进来，保留准星和落点。
- 后三夜选一段两秒的操作高峰做输入实测。玩家向左截瓶的同时向右弹盖，左键接住，随即反向切步，在移动窗缝露出时松开左键。四次操作分别改变盖子落点、持瓶状态、站位和瓶子去向。早松会撞窗沿，晚松会落入下层带，两种结果都要看得出来。
- 一趟最多同时出现两只可接的瓶和一个主动追击者。静音时，瓶底刻痕、管钉行进、手影和方向字幕提供同样的判断线索。
- 录像保存角色走位、方向和游戏内声音事件。关卡用类型安全的 Scala 状态区分空手、持瓶、在带、在空中、已签收；Godot 根据服务端的判定显示接住、脱手或落带。
- 不熟练的玩家漏接仍有一次抢瓶补救。被抓或碎瓶只退回本趟起点，下一次能立即练同一段动作。

## 第一份可玩的原型

先做第四夜的一个房间，包含两条完整可走的解法、一段成功路线上的近脸，以及一次能靠操作救回的失误。试玩重点有三个：玩家能否看出瓶会经过哪里；能否边往左跑边把盖弹向右；危险逼近时，会不会主动舍弃原来的路线。等这三件事在一间车间里成立，再将回收线铺进八夜。
