# 夜班只有三只

单人 2D 像素悬疑游戏。你是夜班送货员奶龙。打烊前，要把三瓶汽水交给玻璃后的奶蛙或奶蛋，并从南门下班。厂里多出的一只只能重演上一单的动作。第一瓶是认识朋友的机会，以后每次交货都会留下新的动作记忆。

## 一次交货

每张工牌在本机首次开班时自动打开图解手册。第一页用车间示意图标出奶龙、收货窗、备用拉杆和南门。玩家确认后才开始收货。其余三页用一组相反手势、一条反弹路径及一次逃生讲解后续规则。玩家可在出货间重读，服务端暂停这一班的计时、投射物和追逐。

试工夜只开正中的 2 号窗。鼠标移到伙伴身上、窗台中央或「左键投这里」提示，点一次左键送一瓶。交班票显示已签收的瓶数。三瓶签收后，用方向键移动到地板最下方正中央的南门，靠近就能打卡。左右地板上的把手是备用泄压拉杆，试工期间闲置。

WASD 或方向键走动，鼠标瞄准，右键向左或向右弹瓶盖，左键投瓶。右键试探时观察每扇窗内伙伴朝哪边伸手。真正的伙伴会追这一次瓶盖，冒牌货朝上一单的方向伸手。上单方向在交班条上。如果两次动作相同，两种反应就一样，玩家可以换边再试。首次记忆来自上个班留下的记录。窗从左到右编号 1、2、3。每单只开放本关指定的窗口，只有一位真正的收货员。真窗每单重新分配。

瓶子沿瞄准线飞行，能从两侧墙反弹一次。错过窗口只损失时间，可以再投。夜班中途有隔离挡板的窗口要求走侧墙反弹路线送入。关卡中的剩余时间表示瓶内压力，归零或把货递给假伙伴都会引来柜下的东西。此时先碰亮起的泄压拉杆，再跑到南门逃离，可从本关第一单重来；没跑出去也可以重试。本关第三瓶送对后走到南门打卡，解锁下一夜。八关逐一解锁，完成过的可以重玩，通关记录跨重启保留。

每个夜班三单。准确投递、走到出口和逃生均由 Scala 判定。试探读数也提供左右符号，能静音通关。误判后的短暂近景与脚步声是惊吓高潮，追逐保留控制权。课堂三分钟可选用已经解锁的夜班切片演示，完整战役另计。

误投时，柜台下的手替你推上插销，冒牌货从最近的营业窗钻出。它起身需要 1.25 秒。它走得比玩家慢，靠近仍然会提前抓住奶龙。先观察拉杆亮在哪边，避开窗口前方，沿外侧去泄压再回南门。第二夜起，偶尔会有一只手从关窗或表盘的反光里重演上一单的方向。

## 造型与构图

沿用奶龙的暖黄色大头、大肚子、圆眼。奶蛙是黄身、浅肚、绿眼与深色小手；奶蛋是轮廓完整的亮黄蛋形与两只绿眼。站立、斜眼、伸手和捧腹的节奏均应在原始像素大小读清。色板为奶油白、麦芽黄、锈红、墨青和煤紫。瓷砖、磨砂玻璃、冷库继电器与手写交班票据形成深夜小厂的空间。暖灯下看得清三只伙伴，暗处同一个动作重演一次才变得可疑。[奶龙官方](https://www.nailoong.com/ipStar/NaiLong/) · [奶蛙参考](https://naiwahub.com/zh/series/nai-wa) · [奶蛋参考](https://naiwahub.com/zh/series/nai-dan)
