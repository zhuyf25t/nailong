# 夜班只有三只 · 守夜版

奶龙在深夜汽水厂送货。上半夜出现的签收铃、备用拉杆和松砖，都能在下半夜找到出处。八夜共用 WASD 或方向键走动、鼠标左键投递或操作、右键弹盖试探。关键台词和环境声有中文字幕。每张工牌首次开班前有图解手册，局内重看会暂停自己的夜班。

## 八夜的难度与目标

| 夜班 | 玩家要做的事 | 线索、失误和节奏 |
|---|---|---|
| 一 · 暖灯试工 | 把三瓶汽水交给正中的 2 号窗，再走到南门打卡 | 不限时，右键选做。伙伴与厂里的声音都有固定位置 |
| 二 · 多出来的一声谢谢 | 朝上单相反的一侧弹瓶盖，把汽水投给看向本次瓶盖的伙伴 | 用两扇窗教会试探。每单只交一瓶，签收声里却会多出一句「谢谢」 |
| 三 · 松动的瓷砖 | 先走过松砖取瓶，再辨认窗内动作并交货 | 砖面开裂约一秒后塌陷，稍后会复原。掉落只重来这一单，裂口里可见托砖的手 |
| 四 · 绕远一点 | 在稳定的侧面平台直投，或用靠中间的平台借侧墙反弹 | 后两单给玩家两条真正可通关的路线。裂砖与站位会改变哪条更省时间 |
| 五 · 三份口供 | 朝相反方向各弹一次，找两次都跟对的伙伴 | 两个模仿者各执一个固定方向，一次试探有歧义。通过两次观察确定唯一真窗 |
| 六 · 地板下面也有一班 | 送完第二瓶下井，比较三窗画面，找出慢两秒的奶龙，再借它踩踏板进门 | 实时动作、延迟动作和首夜记录可用折返或突然停下辨别。旧录像回头时，检修门照常打开 |
| 七 · 它替你上了半班 | 读代签账本，录下行走与停留，再跟实际回放合作穿过两扇互锁门 | 你的走位决定复制体在哪儿、踏板能开多久。路线可在本门重录，最后它会多扶一会儿门 |
| 八 · 别叫醒奶蛙 | 围绕睡着的奶蛙守三轮，追踪四面换位的窗，在机器需要时扶稳它。醒来后试探、认窗、送瓶，最后离厂 | 睡眠环依次倒数 14、18、22 秒。所有换位有连续可见的轨迹。后两轮增加换位与地面威胁，失手只重来本轮 |

## 终夜的游戏边界

- 以房间中心为参照，四面窗都可看见。每轮先让玩家认出奶蛙的起始位置，再让四扇闭窗转动或对调。世界里的北向标记与移动键保持稳定。
- 睡眠进度用环表示。闭眼时不能预先签收，也不能对着四扇窗连点过关。玩家在倒数期间要观察运动，还要离开危险地面并到场操作机器。
- 醒来后有可辨认的试探反馈。强惊吓有明确的画面位置和音效字幕，在成功流程中也会发生。用于解题的唯一一次换位不会藏在遮挡性的近景背后。
- 三轮结束后从值班室东南出口撤出，完成晨班交接。工牌盖上第八枚通关章。

## 画面与声音

前两夜用奶油白、麦芽黄、墨青和暖灯营造熟悉感。第六夜砖下的鲜红手印留下物理痕迹。第七夜沿用相同角色轮廓，签收声处切成黑、白、血红三色，突出玻璃和压机上的伤口与旧血。最后一夜四面环窗、闭眼呼吸、窗轨挪动声和出票口贴脸构成高潮。危险地格、机器操作点和任务字幕始终可读。

奶龙保留暖黄色大头和圆肚，奶蛙是黄身、浅肚、绿眼与深色小手，奶蛋保留完整蛋形与绿眼。[奶龙造型参考](https://www.nailoong.com/ipStar/NaiLong/) · [奶蛙参考](https://naiwahub.com/zh/series/nai-wa) · [奶蛋参考](https://naiwahub.com/zh/series/nai-dan)
