# 夜班只有三只 · 回收线玩家手册

你是汽水厂夜班的奶龙。站位决定你能不能接住瓶子，准星决定瓶子和盖子飞去哪儿。最实用的练习是左手往接瓶点跑，右手同时朝另一边弹盖。

## 第一趟

1. 找地面接瓶圈，先把奶龙移动到圈里。瓶颈靠近时留意场内和检修票上的接瓶提示。
2. 瓶颈到手边时按下左键，保持按住。现在才能带瓶走。依据实际窗口位置瞄准，松开左键送瓶。
3. 漏接或擦到窗框，马上找下层的接瓶点。故意把瓶送进侧带还可以让它沿途播放记录的声音。
4. 认窗时，右键向准星弹盖。真手拦住盖子，假手被盖子穿过。向管口弹盖能调动柜下的东西，击中黄铜拨片能改道。

| 夜班 | 过关所需的操作 | 该看什么 |
|---|---|---|
| 一 | 接住并送出三单，末单弹回后再接一次，到南门打卡 | 白圈、瓶颈和中央收货窗。门前出现的第四只空瓶会播出刚才记录的声音 |
| 二 | 朝窗口弹盖，向能截住盖子的伙伴送货 | 留意盖子是否继续飞和窗缝是否开启。可以在试窗的同时横向截瓶 |
| 三 | 边带瓶边避开开裂的砖，借管响或自己的移动改变怪物调查的位置 | 砖先亮后塌；管钉和手印预告危险位置。失手重试当前这一趟 |
| 四 | 在交叉口直送，或把货送上侧带、拨岔、追到新落点接回再送 | 提前读准轨迹。一条路线少一次接投，另一条能重新找角度，还能把瓶内的声音搬到别处 |
| 五 | 货瓶与空瓶错峰到达。让空瓶进侧线，接下真货并验窗 | 空瓶与货瓶轮廓、色块不同；看道岔方向和两条轨迹，有一只手需要空出来 |
| 六 | 两次交货后打开检修井。用突然停步或右键挥手识别两秒延迟，带声瓶走支线，接回送过检修门，再借回影踩板 | 三块屏幕分别显示现场、延迟和旧录像。声瓶、踏板、门都是场内真实可见的机关 |
| 七 | 站上踏板两秒后封存。第二段既要弹盖开槽、接投，又要沿上侧箭头甩开压辊。到了末闸白线一直按住向右 | 白脸头顶是「你」，另一只写着「录像」。错过末闸只回到白线 |
| 八 | 记住真蛙，闭帘后盯窗、稳机、躲手。第一杆稳住即开放回收带，第二轮要拨岔，第三轮要用声瓶引开假窗并接回。醒后近窗核对、递瓶，走东南门 | 四扇窗持续换位，亮杆旁按住左键扶稳。三轮的睡眠环分别为 14、18、22 秒。第二、三轮必须在本轮归零前完成带线操作，超时回到本轮开头 |

## 碰撞与重试

每秒模拟 20 次。前两夜接瓶时机为 11 tick（0.55 秒），第三至五夜为 7 tick（0.35 秒），后三夜为 5 tick（0.25 秒）。对应的距离容差为 14、12、10 个逻辑像素。可接提示同时考虑时间和位置。看见带子时可以先跑位，到接瓶时机再按左键。

常规漏接有一次下层抢救，碎瓶不会清空之前签收的订单。第七夜过了门可在白线重试。第八夜错投、稳机超时或踩中手，重来当前轮。局内打开玩法说明会冻结自己的当班时钟。

声音记录保存最近的脚步、击管与铃声及其真实间隔。钢钉方向、瓶底刻痕、地面警示和字幕使静音时也可判断。第四夜之后的玻璃近脸发生在签收成功后；最终四窗扑脸在最后一次正确递瓶后出现。
