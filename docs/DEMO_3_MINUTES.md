# 三分钟演示：选任务、改变局势、看回放、改地图

总长 **180 秒**，演示当前已实现的任务、工具、真实过程记录与地图创作。自动化已通过不等于所有浏览器流程已验收；现场能力及尚未覆盖项以 [IMPLEMENTATION_QA.md](IMPLEMENTATION_QA.md) 为准。不要把协议测试数据当成实玩记录。

## 演示前准备，不占三分钟

1. 打开正式前端 5173，确认 Scala API 与 PostgreSQL 正常。5174 的 threejs 原型只验证渲染，不用于证明账号、成绩或回放落库。
2. 用演示账号**亲自完成并保存**一局带 setup 的新版行动，确认成绩、事件摘要、回放分别上传成功；打开 /results/:runId 与 /replays/:runId，检查真实工具/锁定/终局事件能跳转。没有这份实际记录时，先补实玩，不能拿 HTTP fixture 或手写状态冒充录像。
3. 准备一张已经复制到本人名下的草稿，用作工坊演示；确认修改没有影响他人作品。预先试好移动一块箱子、校验、试玩、冻结版本的流程。
4. 预热模型后回到营地，浏览器仅保留营地、真实报告、自己的草稿三个标签。准备记录的真实日期与目标；无需现场重新注册，也不展示密码、令牌或日志。
5. 如要展示代码，只预开 WorldDefinition、RunSetup、SaveTrainingResultAPIMessage 三个文件。不要把三分钟花在安装、搜索、编译或展开全部源码树。
6. 先走一遍下面的时间表，确保按正常键鼠能触发一次扫描与工具效果。必要时降低画质；可备份真实录屏，但播放时明确标注预录。

| 时间 | 屏幕动作 | 可以直接照读的口播 |
|---|---|---|
| **00:00–00:20 · 20 秒** | 营地进入任务地图，分别指向“花谷清场”和“点亮信标”，选择信标任务。 | 「这是浏览器里的单人花谷行动。入口先呈现游戏，正式记录才需要账号。这两项任务的目的不同：一项清除无人机，一项穿过庭院激活信标，再回营地撤离。」 |
| **00:20–00:40 · 20 秒** | 准备页看布局与目标，选择干扰幕；指出另外两工具，点击进入。资源就绪后开始，给倒数留时间。 | 「每局可以带一种工具，也可以不带。我选一次干扰幕，把它留给进入庭院或撤离。服务器会把这局的任务、地图版本、规则和工具冻结下来，之后修改地图不会改变已经开始的局。」 |
| **00:40–01:10 · 30 秒** | 走到侧口观察红色扫描。接近使无人机发现后按 Q，用幕与墙转向；若看不出效果，不强行说已脱锁。随后暂停，不要求三分钟现场通关。 | 「红光是无人机视野；被发现后，它会快速追来。幕只挡视线，不挡身体与子弹，所以要趁这时换位。失去视线的敌机会去最后看到我的地方搜索；已经看见我的追击者也不会被普通子弹打停。」 |
| **01:10–01:50 · 40 秒** | 切到已经核验的真实报告，先说明是预先实玩；打开最后八秒，暂停并跳到一次锁定或工具事件，切俯视，再向前后拖动。 | 「下面是演示前亲自玩过、已经保存的一局。成绩和录像分别保存，所以录像上传失败不会丢成绩。这里记录的是当时的位置、血量、工具和门状态；拖动只读取这些数据，不重新运行现在的 AI，也不会再记一次成绩。若只保留结尾，时间轴会明确标注片段。」 |
| **01:50–02:35 · 45 秒** | 切到本人草稿，拖动一块箱子或修改墙的位置；查看校验，进入真实试玩，观察新掩体，退出试玩后保存并冻结版本。不要为了赶时间忽略保存失败。 | 「同一份世界定义同时驱动画面、移动、子弹和视线。我在这里移动掩体，进入试玩就能验证真实效果。保存草稿会检查重叠和路线；冻结后得到新版本，旧记录和旧回放仍使用原来的地图。」 |
| **02:35–03:00 · 25 秒** | 指向冻结版本，再短暂展示预开的类型与 API 文件，或停在地图与旧报告对照。 | 「前端按 apis、objects、pages 组织；Scala 按账号、局次、记录、世界模块组织。不同 ID 不能混用，网络数据先解码，后端用 IO 和统一事务保存。自动测试已经通过，浏览器与真实设备验收还要按记录继续完成。」 |

时长核对：20 + 20 + 30 + 40 + 45 + 25 = **180 秒**。口播留出点击和观察时间，不需要填满每秒。游戏段可以停在正在探索的状态，不需要冒险赶通关。

## 关键事实提示，不必逐项念出

| 内容 | 当前实际行为 |
|---|---|
| 四机清场 | 全部无人机击毁才胜利 |
| 信标任务 | 近信标按 E 激活，门开启，回营地撤离；不要求全清，无正式 30 秒倒计时 |
| 工具 | Q / 触屏按钮，一局一次；干扰幕 4 秒、诱饵 5 秒、脉冲近身推离并短暂停顿 |
| 无人机 | 约 90°扫描、血条、平滑起飞；未发现时受击高速搜索，看得见玩家且已锁定时受击继续追击 |
| 三节课堂 | 各 30 秒；分别练激活撤离、真正脱锁、工具实际生效，不保存账号成绩 |
| 回放 | 基础 10Hz，关键段更多实际采样；原镜头/俯视、倍速、扫描/路线、事件前两秒定位 |
| 录像预算 | 完整最多 10 分钟；5MiB 软预算、6MiB payload 硬上限，超预算保留末尾片段并如实显示范围 |
| 档案 | 数据库成绩与过程；收藏是按账号区分的本机偏好，跨设备不自动同步 |
| 地图编辑 | SVG 俯视编辑，真实 Three.js 核心试玩；草稿可改，冻结版本不可覆盖 |
| 地图校验 | 出生到信标按关门检查，信标到撤离按开门检查；通过几何检查不代表难度已获真人认可 |

录像是有限采样后的复盘视图，部分移动采用插值、粒子简化；不能承诺骨骼或每个像素与现场完全一致。它不是事后根据总分生成的动画，也不是通过当前 AI 重模拟的战斗。

## 现场备用，不延长时间或伪装结果

| 情况 | 立即动作 | 说明 |
|---|---|---|
| API 或登录不可用 | 保留错误，改为公开练习展示操作；数据库与工坊只展示已核验材料 | 「当前服务连接失败，接下来是本地练习，不能算新成绩落库。」 |
| 30 秒内没有出现清楚的追击/脱锁 | 暂停并按时切真实报告；可播放提前录好的真实片段 | 「这次现场尚未出现清楚的脱锁，下面使用提前实玩记录复盘。」 |
| 正式成绩尚未保存 | 显示待传与重试状态，使用事先保存的真实记录继续 | 「当前成绩仍在等待上传，这不是已经保存成功。」 |
| 成绩成功但回放上传失败 | 分别指出两个状态，可使用本人 IndexedDB 的真实本机副本 | 「成绩已保存，录像还在独立补传；现在播放的是本机记录。」 |
| 回放显示片段 / 旧记录无录像 | 保留覆盖说明或 missing_legacy，选已核验的新局 | 「这局只保留这些时刻 / 旧局没有采集录像，无法事后补造。」 |
| 草稿保存冲突 | 保留冲突提示，重新读取后再修改；演示到当前可证实状态即止 | 「另一个页面已经修改过，修订号阻止我覆盖它。」 |
| 工坊试运行加载过慢 | 不现场反复重载；展示实际保存的新版本及可验证几何 | 「试玩仍在加载，我先展示已保存版本，当前画面不能证明三维运行完成。」 |
| 某个浏览器验收项未完成 | 依据 QA 记录说明范围，不把脚本当执行证据 | 「这项还没有完成实际浏览器验收，当前只展示已确认部分。」 |

正式行动、公开练习、课堂与工坊试玩要明确区分。只有本人正式 RunId 的成功响应和可重新查询的数据库记录能证明落库；计分画面、localStorage、截图与 HTTP 合成轨迹都不能单独证明实玩通关。
